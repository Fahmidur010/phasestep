# Phase execution plans

Per-phase plans generated by `/plan-phase <slug>` (named build phases). **Steps inside each plan stay numeric.**

| File | Phase id | Status |
|------|----------|--------|
| `phase-auth.md` | `auth` — Authentication | (after plan-phase) |

Legacy: `phase-1.md` / `/plan-phase 1` still resolve when those files or BUILD_PLAN order map them.

**Workflow:** plan → build (+ Behavior delta with WHEN/THEN scenarios) → intent → verify → … → audit → complete  

See [`docs/PHASESTEP.md`](../PHASESTEP.md).

Progressive: `/plan-phase <slug>` → Mode progressive → steps filled at each `/build-phase <slug> N`.
